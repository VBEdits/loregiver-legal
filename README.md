# loregiver-legal

Documentos legales de las aplicaciones de **Loregiver**, publicados con
GitHub Pages porque Google Play exige que la politica de privacidad este en
una **URL publica** y accesible sin descargar nada.

Este repositorio es publico A PROPOSITO y solo contiene texto: el codigo de
los juegos vive en otro sitio y sigue siendo privado.

La fuente de verdad de la politica de Bars & Balls es `docs/privacidad.md`
del repositorio del juego. Lo que hay aqui es la version publicada, sin la
nota interna dirigida al desarrollador.
